Type system

Three faces, three jobs. Archivo Black shouts the headings, IBM Plex Sans carries the reading, and JetBrains Mono marks everything a programmer would read character by character: code, labels, chips, the nav, stats, countdowns and prices.

Sources: tokens/tokens.json → css/tokens.css (scale, leading, tracking) and css/type.css (faces, roles). Live site only; ?static=1 keeps the mockup fonts.

Fluid scale

Utopia method: each step grows linearly from a 360px viewport (base 16px, ratio about 1.17) to a 1536px viewport (base 18px, ratio about 1.24). Written as clamp(rem, rem + vw, rem), so zoom and the user's font size still scale it, and no step grows more than 2.5× (WCAG 1.4.4).

  • step-6 · 43→67HERO
  • step-5 · 36→54PAGE TITLE
  • step-4 · 30→43SECTION
  • step-3 · 25→34Section head
  • step-2 · 21→27Sub-head
  • step-1 · 18→22Card title, lead text
  • step-0 · 16→18Body copy and every form control
  • step--1 · 14→15Small UI text, table cells, nav
  • step--2 · 12→13Meta, captions, timestamps (the floor)
