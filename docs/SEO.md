# Search and AI-search setup (r13 seo)

Everything search engines and AI assistants read is generated by `tools/build.py` through `tools/seo.py`. Do not hand-edit
`sitemap.xml`, `robots.txt`, `llms.txt`, or the `<head>` tags of the built pages.

## Where things come from
| What | Source |
|---|---|
| Page title + description | the `{{HEAD title=".." desc=".."}}` line of `src/<page>.html` (unique per page; tests/seo.test.mjs checks length and uniqueness on indexable pages) |
| Canonical origin | env `SITE_URL`, else `src/data/site.json` `site_url` (now the placeholder `https://site-url.invalid`) |
| Indexable or not | `tools/seo.py indexable()`: public to a signed-out visitor in `src/data/access-policy.json`, no `noindex` on the HEAD line, not in `site.json noindex_pages`, and no legal "DRAFT — review by a qualified" banner |
| JSON-LD | one `@graph` per page: Organization + WebSite everywhere; WebPage + BreadcrumbList on indexable pages; FAQPage from the visible `<details><summary>` in a `*faq*` section; ItemList of Course from the landing's `.e-pcard` cards. Only visible content is marked up. |
| sitemap.xml / robots.txt / llms.txt | the indexable set |
| Preview / vercel.app hosts | `vercel.json`: `X-Robots-Tag: noindex` for `*.vercel.app`. Combined deploy: `backend/next.config.mjs` sends `X-Robots-Tag: noindex` on every path unless `VERCEL_ENV=production` and `SITE_INDEXING=on`; `/api` is always noindex. |

## Launch checklist (domain go-live)
1. Decide the domain. Set `SITE_URL=https://<domain>` on the Vercel project (combined deploy: `scripts/copy-static.mjs` rewrites the placeholder in the copied pages), or set `site_url` in `src/data/site.json` and rebuild.
2. Set `SITE_INDEXING=on` on the production environment only.
3. Remove the legal DRAFT banners once the advocate signs off: privacy, terms and the other legal pages become indexable automatically.
4. Verify the domain in Google Search Console, submit `https://<domain>/sitemap.xml`, check URL Inspection on `/`, and watch the Generative AI performance report.
5. Run `node --test tests/seo.test.mjs` with `SITE_URL` set to the real origin.

## Notes
- No `SearchAction`: Google retired the sitelinks search box on 21 Nov 2024 and 101 has no public search URL.
- FAQ rich results stopped appearing in Google Search on 7 May 2026; FAQPage stays only where a real FAQ is on the page.
- `llms.txt` is ignored by Google Search (Google's generative AI guide); it is kept for other assistants and costs nothing.
- Never add review/rating markup, partner logos or counts unless they are real and visible on the page.
